# NSP Portfolio Builder — قرارداد ورود پروژه ZIP (نسخهٔ آزمایشی V268)

## هدف
ساخت خودکار صفحه‌های کاملاً لایه‌بندی‌شده، با یک فایل ZIP شامل JSON و تصاویر. کاربر فقط ZIP را وارد می‌کند؛ ایجاد دستی لایه‌ها شرط پذیرش نیست. هدف کم‌کردن وابستگی به طراح است، نه جایگزینی تمام امکانات فتوشاپ.

## ساختار استاندارد بسته

```text
NSP-Portfolio-01-Cover-Trial.zip
├── project file/
│   └── Portfolio-01/
│       └── project.json
├── Image/
│   └── hotel-room-legrand-sample.jpg
└── README.txt                   # اختیاری
```

- دقیقاً یک فایل `project.json` در مسیر بالا یا در ریشه ZIP مجاز است.
- JSON باید `app="NSP Portfolio Builder"`، `kind="NSP-Project-Backup"` و `schemaVersion=2` داشته باشد.
- فایل‌ها باید شناسهٔ یکتا داشته باشند. تصویر به صورت رکوردی در `project.data.imageLibrary` و با `id` قابل ارجاع است.
- مسیر تصویر در کتابخانه، نسبت به محل `project.json`، مانند `../../Image/hotel-room-legrand-sample.jpg` است. در `visualObjects` از `assetId` استفاده شود، نه URL خارجی.
- `project.data.portfolios[].pages[].visualObjects` شامل المان‌های مستقل با `type`، مختصات `x,y,w,h`، `layerId`، و برای متن، `text,fontFamily,fontSize` است. `layers` باید اسامی و شناسه‌های همخوان داشته باشد.
- برای A4 افقی: `pageStyleOverrides={"paperSize":"A4","orientation":"landscape"}`. بوم داخلی نرم‌افزار: ۱۱۹۱ × ۸۴۲.
- متن فارسی در JSON قابل ویرایش است. فونت در فایل ZIP قرار نمی‌گیرد و باید روی رایانهٔ کاربر نصب باشد.

## مسیر کاربر

۱. در صفحه «پروژه‌ها»، «ورود پروژه ZIP» را انتخاب کنید.
۲. ZIP را انتخاب کنید؛ نرم‌افزار تصاویر را از بسته می‌خواند و پس از اعتبارسنجی، با شناسه‌هایشان در کتابخانه وارد می‌کند.
۳. صفحه را باز کنید؛ هر عکس، متن و شکل باید در لایهٔ مستقل دیده و ویرایش شود.

## اعتبارسنجی و محدودیت‌ها
- قبل از تغییر پروژه، فهرست فایل‌ها، مسیرها، CRC و وجود تمام تصاویر بررسی می‌شود.
- مسیرهای نامعتبر، ZIP رمزدار، چند ZIP تکه‌ای و شناسه‌های تصویری گم‌شده رد می‌شوند.
- حداکثر اندازه ZIP: ۶۴ MiB؛ هر فایل استخراج‌شده: ۲۴ MiB؛ مجموع استخراج‌شده: ۸۰ MiB.
- روش‌های فشرده‌سازی `STORE` و `DEFLATE` پشتیبانی می‌شوند. DEFLATE به `DecompressionStream('deflate-raw')` مرورگر وابسته است؛ بسته آزمایشی بدون فشرده‌سازی ساخته شده است.
- این مسیر در سورس ثبت شده و تست واحد خواندن ZIP (ورودی صحیح و CRC خراب) انجام شده است؛ **بازشدن واقعی فایل در مرورگر و Windows/Tauri هنوز باید توسط مالک بررسی شود**.
- عکس نمونه از PDF مرجع Legrand است؛ برای انتشار تجاری، مجوز تصویر و وضوح ۳۰۰ DPI را جداگانه بررسی کنید. لوگوی موجود فقط جای‌نگهدار است.

- عکس موجود باشد، عنوان و زیرعنوان فارسی و نام برند موقت مستقل و قابل ویرایش باشند.
