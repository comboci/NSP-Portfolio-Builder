## شواهد اجراشده

- از ریشهٔ مخزن: node scripts/v290-audit/run.cjs. هشت fixture مبتنی بر کد واقعی و داده‌های مصنوعی، شامل بستهٔ نمونه، هفت حالت بازیابی journal، صف، هویت، قالب‌ها، ظاهر Slot، داده و زبان PASS.
- node scripts/static-check.cjs --all. دو Gate متن سورس PASS: Browser با ۴۴ اسکریپت و Native با ۲۰ اسکریپت و schema 13؛ فقط parse و قرارداد سورس.
- git diff --check بدون خطا. دادهٔ واقعی، مرورگر ماندگار، IndexedDB واقعی، انتخابگر فایل، PDF/ران‌تایم عملی، Windows، Native/Tauri، CI، Office و Deploy اجرا نشدند. تلاش مستقل مرورگر به نبود باینری Chromium در محیط رسید. تست مرورگر روی همین SHA پیش از استفاده روی اصل داده ضروری است.

## حدود طراحی و ریسک پذیرش

نحوهٔ ذخیرهٔ محلی به دسترسی File System و Web Locks و IndexedDB مرورگر وابسته است. اگر نتیجه قابل اثبات نباشد بازیابی تغییر نمی‌دهد و امکان بررسی نسخه‌های قبل/بعد را می‌دهد. اصل تصویرهای مشترک ZIP در rollback خودکار حذف نمی‌شوند، چون ممکن است جاهای دیگر ارجاع داشته باشند؛ ممکن است بایت استفاده‌نشده باقی بماند. هیچ انتساب یا حذف خودکار برای ارجاع سامانهٔ قدیمی انجام نمی‌شود. PDF با اندازهٔ زونکن A4 افقی، حاشیهٔ حلقهٔ امن بدون متن/لوگو و تداوم پس‌زمینه، جداگانه باید اندازه‌گیری شود.
