# Portfolio-02 NSP Resume Templates — چهار صفحه پایهٔ قابل تکثیر

این مشخصات برای پروژهٔ نمونه‌ای است که کاربر بر اساس PDF «Rezome nsp. 3.pdf» درخواست کرده است. ساختار ZIP مطابق قابلیت **ورود پروژه ZIP** نسخه V268 است.

## محتوای پروژه
- نام: `Portfolio-02 NSP Resume Templates`
- پوشه: `project file/Portfolio-02/`
- صفحه ۱: جلد فارسی با تصویر واقعی هتل و عنوان قابل ویرایش
- صفحه ۲: معرفی شرکت، شش آیکون خدمات و چهار شاخص آماری
- صفحه ۳: معرفی تک‌هتل؛ نمونهٔ هتل سارینا با اطلاعات مکانی، سال اجرا، GRMS و IPTV
- صفحه ۴: چهار کارت مستقل برای هتل‌های النبی، رز، توریستی لاهیجان و لاله
- فونت پیشنهادی: `Vazirmatn` (در فایل ZIP توزیع نمی‌شود)
- رنگ‌های اصلی: سرمه‌ای `#112B40`، نارنجی `#F39324`، سفید و خاکستری
- کاغذ: `A4` افقی؛ بوم داخلی 1191×842
- تمامی متن‌ها و تصاویر، شیء مستقل در `visualObjects` هستند و با `layerId` دسته‌بندی شده‌اند.

نمونه از عکس‌های موجود در PDF ارسالی کاربر ساخته شده است. فایل ZIP قابل ایمپورت در Library شخصی پروژه با نام بالا قرار دارد؛ **به‌دلیل وجود عکس‌های منبع و حقوق نشر، فایل‌های تصویری در این مخزن عمومی منتشر نشده‌اند.** این مستند به‌تنهایی جایگزین ZIP نیست.

## وضعیت آزمون
- ZIP ذخیره‌شده بدون فشرده‌سازی، مطابق ZIP_STORED
- ۴ صفحه؛ ۱۵ رکورد تصویر/آیکون؛ ۱۰۷ شیء قابل ویرایش
- بررسی CRC و رد فایل تغییریافته با آزمون parser نسخه V268: موفق
- تست Runtime داخل خود برنامه در سیستم کاربر: انجام نشده
- قالب‌ها به صورت چهار «صفحهٔ پایهٔ مستقل» هستند؛ برای تولید نسخه‌های بیشتر، صفحه را Duplicate کنید. این بسته قالب‌های عمومی مشترک سراسری ایجاد نمی‌کند.

## معیار پذیرش مالک
ورود ZIP از بخش پروژه‌ها، مشاهده ۴ صفحه و همهٔ تصاویر، اصلاح یک متن، جایگزینی تصویر و تکثیر صفحهٔ تک‌هتلی بدون ساخت دستی لایه؛ سپس ذخیره و بازگشایی مجدد برای بررسی پایداری.
