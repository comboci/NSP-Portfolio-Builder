# تصمیم ممیزی سورس Browser V343

**آمادهٔ Merge برای Runtime Test مالک، مشروط به آزمون روی همین کاندید.** ۳۱ مسیر در ۸ حوزهٔ درخواستی و محل اتصال آن‌ها در ۵۶ تگ script فهرست شدند. ۱۰ گروه ایراد مستند در شاخهٔ مهندسی اصلاح شد. در مسیرهای جدول مانع سورسیِ تأییدشدهٔ باز برای شروع آزمون مالک باقی نماند. انتشار عمومی همچنان به شواهد اجرایی و تأیید مالک نیاز دارد.

مبنای سورس `c149243390334d0f4be96500e9af7afc9ae058dc` و main هنگام مرور `b7deb97ce05ed171aa23db4c2d44caeab4c2f0ee` بود. کاندید ثابت، **Commit حاوی همین فایل** در شاخهٔ `engineering/graphics-engine-evolution` است. در زمان بررسی، main جد مستقیم کاندید بود. مسیر مستقل SHA در لینک Commit و گزارش تحویل ثبت می‌شود. دامنهٔ این کار شامل نوشتن در main نیست.

## وضعیت شواهد

۲۴۹ ردیف قبلی به همان ترتیب و شناسه حفظ شد. ۱۰ ردیف یافته و ۱۰ سناریوی هدفمند اضافه شد. هر ۲۶۹ ردیف اجرایی **NOT_RUN** است. شمارش ۵۶ تگ، seed و کاتالوگ خارجی را هم شامل می‌شود. جدول بلوک‌ها مرز داده، پوسته و کد مسیرهای محصول را مشخص می‌کند. شواهد اجرایی V333 به این SHA منتقل نشده است.

ریسک شناخته‌شدهٔ سازگاری مربوط به Workspace قدیمی V342 است که بعد از حذف آخرین پروژه و Import غیرفعال ذخیره شده باشد. دادهٔ آن ممکن است میزبان خالی را مثل پروژه‌ای واقعی به نام «بدون پروژه» نشان دهد. V343 در حالت مبهم رکورد را حفظ می‌کند. برای صفحات قدیمی بدون پورتفولیوی مالک، مسیر نگهداری RAW در دسترس است؛ دادهٔ از پیش بازنویسی‌شده قابل بازسازی از این تغییر نیست.

مرور سورس DEC-006 شامل اجرای برنامه، Static Checker، Build، CI/CD، PDF یا دسترسی به دادهٔ عملیاتی نبود. زمان‌بندی واقعی IndexedDB و Web Locks، مجوز دیسک، قطع عملیات، IME، فونت/چاپ، کارایی ۱۰/۱۰۰/۵۰۰ صفحه و Windows/Native در انتظار شواهد مالک هستند.
