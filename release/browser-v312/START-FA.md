# Browser V312 | A09

- GE-009: محاسبهٔ شمارهٔ مشترک به تابع خالص Scene منتقل شد؛ یک wrapper و یک script اجرایی حذف شد. Editor همچنان بخش‌هایی از adapter تک‌فایلی دارد. خروجی HTML مستقل و آفلاین حفظ شده. اسکریپت مالک تطابق دقیق ۱۱ ماژول، ترتیب و فایل اضافه/ناقص را کنترل می‌کند.
- GE-010: کپی دوم اشیای Snapshot که از قبل مستقل بودند حذف شد؛ برای تاریخچهٔ چندصفحه‌ای تنها صفحات تغییرکرده نگهداری می‌شوند. سقف مستند قبلی ۱۰۰ عمل در هر صفحه تغییر نکرد. بودجه سراسری بدون حذف سابقه هنوز نیازمند اندازه‌گیری و سیاست است.
- GE-011: فقط ترسیم پیش‌نمایش و راهنما به frame موکول می‌شود؛ نمونهٔ هندسی معتبر و تصمیم نهایی از رویداد جاری‌اند. Frame معلق در خروج لغو می‌شود. تکرار رندر بخش تاریخچه در مسیرهای refresh/render حذف شد. هزینهٔ Resolve و جست‌وجوی Snap و ساخت پوستهٔ صدها صفحه هنوز اندازه‌گیری نشده است.
