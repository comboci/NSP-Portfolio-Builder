- **سازگاری:** plain text قدیمی نیازی به migration ندارد؛ متن برداری Illustrator و طراح جایگاه‌های هتل همان مسیر قدیمی را دارند و ویرایش غنی جدید به آنها تحمیل نشده است. رندر Layout هتل، Project JSON schema، Native و سرور تغییر نکردند.
