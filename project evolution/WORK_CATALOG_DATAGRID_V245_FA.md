# Work catalog DataGrid — V245

در عملیات ← کتابخانه تحقیق Work ← شرکت‌ها و کاتالوگ‌ها، جدول کاتالوگ‌های تکمیلی ستون‌های نام، سال، نوع، آنلاین و داخلی دارد.

دریافت داخلی تنها پس از انتخاب پوشه توسط کاربر و تأیید فایل PDF با امضای %PDF- فعال می‌شود. انتخاب پوشهٔ مادر یا خود NSP_Research_Resources پشتیبانی می‌شود. فایل‌های نامعتبر به عنوان فایل دانلودشده گزارش نمی‌شوند.

امکان اتصال پوشه در مرورگرهای فاقد File System Access API موجود نیست؛ در آن مرورگرها لینک‌های رسمی آنلاین همچنان فعال‌اند. پس از F5، پوشه باید مجدداً انتخاب شود. نام‌گذاری فایل باید با دانلودکنندهٔ خود برنامه مطابق باشد.

تمپلیت‌های آماده به فایل ← تمپلیت‌های آماده منتقل شده‌اند و مدیریت قالب‌های ثبت‌شده در فایل ← طراحی قالب‌ها باقی مانده است.

تست اجرایی لازم: انتخاب پوشه خالی و پر، PDF موجود سالم و نامعتبر، مرورگر فاقد مجوز، دانلود و توقف؛ بررسی وضعیت پس از بازکردن دوبارهٔ کتابخانه.
