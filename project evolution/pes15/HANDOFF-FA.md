## وضعیت اجرایی

آداپتور سمت Python (`adapter.py`) به صورت Opt-in در مسیر جدید `project evolution/pes15/` ثبت شده است. ورودی آن کپی فایل PES-14 است. مهاجرت در حافظه انجام می‌شود؛ Schema و قواعد معنایی PES-15 کنترل شده و تنها در یک پوشه تازه، خروجی JSON، SQLite مستقل، فایل Context و Backup ساخته می‌شوند. خروجی موجود بازنویسی نمی‌شود. ناسازگاری داده، عملیات را متوقف می‌کند.

**این نسخه فقط Sidecar/CLI است.** UI یا Tauri برنامه هنوز به آن متصل نشده و هیچ پردازش زمان‌بندی‌شده‌ای از PES-14 به PES-15 منتقل نشده است.

## ممیزی فایل واقعی GitHub

توسط اتصال GitHub و روی SHA ثابت بالا، فایل واقعی PES-14 به صورت Read-only بررسی شد:

- **۱۳۲ رکورد** در ۱۵ دسته؛ ۱۰ Scope و صفر Relationship مستقل.
- **۳۴ Task** فاقد Priority ثبت‌شده و **۳۹ Observation** فاقد `observed_at` هستند؛ این ابهام تاریخی باید حفظ شود.
- در بررسی اولیه، شناسه تکراری، ارجاع شکسته رکورد/Scope/Contract یا Scope چرخه‌ای مشاهده نشد.
- `main` در خلال عملیات جلو رفت؛ آمار بالا مختص SHA معین است، نه الزاماً تازه‌ترین وضعیت هنگام خواندن این سند.

**محدودیت مهم:** اجرای Python `migrate_v14`/`validate` روی تمام **۱۳۲ رکورد واقعی** انجام نشد، چون فایل GitHub توسط اتصال خوانده شد ولی فایل اصلی به محیط اجرای محلی منتقل نشد. این مرحله صرفاً یک *preflight ساختاری/ارجاعی* از تمام رکوردهای واقعی است و نباید به عنوان تأیید قطعی مهاجرت کامل اعلام شود.
