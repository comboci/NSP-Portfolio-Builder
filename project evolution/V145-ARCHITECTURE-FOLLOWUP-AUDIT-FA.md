- فایل‌های Rust و SQLite در مخزن باقی‌اند؛ Tauri package نسخه `138.0.0` و SQLite schema نسخه `13` است.
- تنها توسعه مرورگر/IndexedDB به نسخه HTML V145 رسیده است. این به معنی حذف واقعی SQLite از سورس یا قطع کارکرد مسیر native نیست.
- پایگاه‌های مرورگر و SQLite مستقل‌اند؛ ادعای همگام‌سازی یا Reset داده وجود ندارد.
- وضعیت تغییر شکل ساختار Native به فاز `deferred_sqlite_phase` مربوط است.

3. **TASK-049 — P1:** V144 کد نشر واردات نرمال‌شده را دارد، پس Planned قبلی نادقیق بود؛ در PE به in_progress/Runtime pending منتقل شد.
4. **TASK-052 — P1:** V143 از ذخیره ساختاری استفاده می‌کند اما اگر ACK غیرهمزمان شکست بخورد rollback کاملِ ترتیب در حافظه ندارد و کاربر باید بررسی کند؛ وضعیت به in_progress تغییر یافت.
5. **TASK-048 / TASK-026 — P1:** Manifest ورودی/خروجی برای Template، Styles، Component، تصاویر و داده‌های پروژه‌های قبلی باید از مدل قدیمی Master/Section به Page-First منتقل شود.
