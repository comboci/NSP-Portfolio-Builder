# NSP Portfolio Builder — Work Research Catalogs

تاریخ بررسی: 2026-11-21. این پوشه در مسیر رسمی `project evolution` قرار دارد و به **پورتفولیوی سازمانی NSP** اختصاص دارد.

- `catalogs.json`: 15 منبع تکمیلی رسمی از شش شرکت، همراه لینک PDF/صفحه دانلود، وضعیت بررسی و ایده طراحی.
- `reference-index.pdf`: نمایه PDF *تهیه‌شده توسط NSP* با لینک‌های قابل کلیک به منابع اصلی ناشران. این فایل جایگزین یا کپی کاتالوگ‌ها نیست.
- `index.html`: نمایش همین اسناد در «عملیات ← کتابخانه تحقیق Work» در کنار هفت مدخل قبلی.

## وضعیت بررسی
`reviewed`: نمونه صفحه‌بندی مستقیماً مشاهده شده؛ `partial`: بخشی از منبع مطالعه شده؛ `indexed`: لینک رسمی تأیید شده اما بررسی بصری کامل نیست.

**حقوق نشر:** حق بازنشر PDF شرکت‌ها در یک مخزن عمومی احراز نشده است. به همین دلیل فایل‌های خود شرکت‌ها در GitHub کپی نشده‌اند؛ مسیر دانلود رسمی و صفحه ناشر برای دریافت مستقیم ثبت شده است. بعضی لینک‌ها تغییرمسیر، امضای موقت یا محدودیت منطقه‌ای دارند؛ فیلد `sourcePage` برای مسیر جایگزین است.
