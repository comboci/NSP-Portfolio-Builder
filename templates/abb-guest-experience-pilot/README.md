# NSP — ABB-inspired Guest Experience · Pilot Wizard

این پوشه **یک نمونهٔ آزمایشی مستقل** برای بازبینی طراحی و تجربهٔ کار با ویزارد است. تمپلیت از ساختار بصری کاتالوگ ABB الهام گرفته، اما از لوگو و گرافیک اختصاصی ABB کپی نمی‌کند.

## اجرا

1. مخزن را به صورت کامل با `Code → Download ZIP` دریافت و Extract کنید (یا Git Pull بگیرید).
2. فایل `templates/abb-guest-experience-pilot/wizard-standalone.html` را در Chrome یا Edge باز کنید.
3. ویزارد چهارمرحله‌ای را تکمیل کنید: برند و لوگو، تصویر هتل و کنترلر، متن‌های معرفی، چهار ویژگی. تمام ورودی‌ها اختیاری‌اند و نمونهٔ پیش‌فرض قابل‌بررسی است.
4. دکمهٔ «ساخت صفحه و ورود به ویرایشگر» را بزنید. آبجکت‌های جداگانه را تغییر دهید و خروجی JSON یا چاپ/PDF بگیرید.

**از منوی «فایل ← تمپلیت‌های آماده» در `index.html` نیز لینک اجرای نمونه اضافه شده است. این مسیر فقط وقتی کار می‌کند که پوشهٔ `templates` کنار `index.html` حفظ شده باشد.**

## فایل‌ها

- `wizard-standalone.html`: نسخهٔ تک‌فایلی با عکس‌ها و SVGهای Embedded؛ بدون اتصال به اینترنت
- `template.json`: ساختار `nsp.visual-template-pack.v2` شامل یک صفحهٔ A4 افقی، ۴۶ آبجکت و ۶ آبجکت تصویر با داده‌های Embed شده

## محدودیت‌ها و وضعیت تأیید

- این نمونه هنوز **داخل موتور ذخیره/بارگذاری `index.html` ادغام نشده**؛ لینک منو فقط نسخهٔ مستقل را باز می‌کند.
- واردکنندهٔ فعلی تمپلیت‌ها از `nsp.visual-template-pack.v2`، تصاویر Embed شده و صفحهٔ Landscape پشتیبانی نمی‌کند.
- در آزمایش Chromium با محتوای HTML: چهار مرحله، تغییر متن و عکس، خروجی JSON و صحت تصاویر بررسی شد؛ خطای JS مشاهده نشد. اجرای فایل روی محیط کاربران نیاز به تست دارد.
- تصاویر و آیکون‌ها نمونهٔ بصری هستند، نه عکس محصول، آمار فنی یا ادعای تأییدشدهٔ NSP.
- عکس‌های انتخابی کاربر در مرورگر پردازش می‌شوند و از ویزارد به سرور ارسال نمی‌شوند.
